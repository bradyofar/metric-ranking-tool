How this works

This tool scores your data fairly using an advanced Re-standardized Logistic Sigmoid pipeline. It standardizes each component metric against its group average, compounds them based on your custom weight configuration, and runs a secondary standardization over the final composite values. This allows us to map every cohort cleanly onto an intuitive, bounded 0 to 100 Performance Index Scale.

Each individual metric component is isolated by calculating its distance from the cohort average via Standard Deviations ($Z$-scores):

  • Index Score of 50 — Represents the absolute cohort mathematical average.
  • Index Score above 50 — Above-average performance ($>0$ standardized composite deviations).
  • Index Score below 50 — Below-average performance ($<0$ standardized composite deviations).
  • Weights determine the proportional balance. Modifying total value spans does not break performance curves (e.g., 1:2:3 outputs identically to 10:20:30).
  • Cost inversion handles expenses — Lower monetary raw values systematically elevate baseline component score structures.
  • Consistent Bounding — The logistic transformation mathematically caps boundaries to protect presentation tables from blowing out due to severe outlier anomalies while entirely preserving intra-cohort scaling gaps.
