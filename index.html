How scoring works

Each metric is standardised relative to the group using sample standard deviation (Bessel's correction applied), so small datasets are handled accurately.

  • Baseline: Scores are centred around the dataset average (0 for Z-Scores, 50 for Points).
  • Positive Metrics (MAX): Higher values improve ranking score.
  • Efficiency Metrics (MIN): Lower values improve score — e.g. CPA, Bounce Rate, Unsubscribe Rate.
  • Cross-dataset balance: Performance and efficiency metric groups are independently normalised before combining, so an unequal number of metrics in each group does not bias the composite.
  • Zero-variance warning: If all entries share the same value for a metric, that metric is excluded and flagged — it carries no discriminating information.
